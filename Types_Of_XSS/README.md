## Types_Of_XSS

### REPO này chứa Source Code ứng dụng WEB PHP

Dựa theo các dạng XSS, Repo này chứa Source Code ứng dụng WEB PHP tồn tại lỗ hổng XSS theo các dạng như :
- DOM based
- Reflected
- Stored

Mục đích xây dựng ứng dụng : 
- Nắm rõ hơn về 3 dạng lỗi XSS
- Thực hành với các Exploit Development nâng cao (Cái này tự xây dựng nhé)

Dom based và Stored đã được đóng gói docker.

*Hack to learn not learn to hack!*
