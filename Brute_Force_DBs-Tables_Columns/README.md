## Brute_Force_DBs-Tables_Columns

### REPO này chứa Source Code ứng dụng WEB PHP với design pattern MVC
Có tính năng đăng nhập

Tồn tại lỗ hổng SQL Injection khi không validate Input và không sử dụng Prepared Statement

### Công cụ brute force "brute-force-tools.py"
Công cụ này có tính năng brute-force tuần tự
- databases name
- tables name
- columns name
*Công cụ này hoạt động theo cơ chế khai thác lỗi time-based. Chỉ cần run là dump hết databases,tables,columns*
