## WEB TO TEST SQL INJECTION

### REPO này chứa source code ứng dụng web Java JSP Servlet với design pattern MVC, Maven

Có các tính năng như : 
- Đăng ký
- Đăng nhập
- Searching
Tồn tại lỗ hổng SQL Injection khi không validate Input và thực hiện Statement thay vì Prepared Statement.

### REPO này cũng chứa Write Up khai thác lỗ hổng SQL Injection với các dạng khác nhau

Write Up khai thác lỗ hổng SQL Injection với các dạng như :
- UNION based
- Error based
- Blind True/False
- Time based (manual)
- Time based (Python Script)
- SQL Injection to RCE (Remote Code Execution)
